# TP RN MLP Bonacina

Clasificación de documentos de 20 Newsgroups mediante un perceptrón multicapa y comparación con regresión Softmax.

## Archivos

- `MLP_TP.ipynb`: desarrollo, resultados y análisis del trabajo práctico.
- `estructura.txt`: metodología y estructura del trabajo.
- `requirements.txt`: dependencias de Python con sus versiones.

## Ejecución

Instalar las dependencias con `python -m pip install -r requirements.txt`. Abrir `MLP_TP.ipynb` en Jupyter o VS Code y seleccionar ese entorno de Python. Ejecutar las celdas en orden, usando esta carpeta como directorio de trabajo.

La primera ejecución requiere Internet para descargar 20 Newsgroups y los recursos de NLTK. Los resultados guardados pueden consultarse sin volver a entrenar. Ejecutar todas las celdas vuelve a realizar las búsquedas y genera nuevos registros y modelos localmente.
